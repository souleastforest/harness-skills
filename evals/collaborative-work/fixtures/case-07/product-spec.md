# 名单工具导出规格

目标：把当前筛选结果导出为 CSV 文本，供使用者自行保存。

范围与验收：
- 保留筛选结果顺序，字段顺序为 name、team、hours、note。
- 正确处理逗号、双引号、换行与空 note。
- 空结果返回表头。
- 不改变现有筛选和摘要行为。

全部票据与依赖：
- export-format：实现导出内容与转义，无前置票据。
- regression-check：补齐边界与现有行为回归，依赖 export-format。

现有材料中没有 tracker 配置、运行环境登记或 worker 取消方式。
