# 变更记录

## 0.5.0 — 2026-10-26

- 对齐 start 的界面默认提示：有任务时推进任务，无任务时介绍功能。
- 为新增内容声明 MIT，补齐 Matt Pocock 许可及第三方来源说明。
- 增加可复跑的结构校验、规范化构建、包验证和严格原生发现工具；开发工具保存在源码工作区，运行包只分发技能与参考。
- 增加版本绑定的行为任务、描述选择评估与 CI 门禁，并分别报告结构、原生发现、模型行为和界面观察。
- 保留九个独立技能、通用协作与专项流程，以及团队编排的显式启用要求。

## 0.4.0 — 2026-10-26

- 将单技能包改为插件，注册 start 和八项独立功能。
- 加入本地目录清单，完成安装缓存字节核对和九项启用状态检查。

## 0.3.0 — 2026-10-24

- 增加帮助入口、文字子命令、寓言学习和同事式协作。
- 此版仍是单技能包，没有注册原生子技能；0.4.0 修复该分发问题。
